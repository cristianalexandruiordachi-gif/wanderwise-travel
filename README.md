# WanderWise Travel

A responsive travel recommendation website for the JavaScript Programming Essentials final project.

## Features
- Home, About Us, and Contact Us pages
- Case-insensitive beach/beaches, temple/temples, and country/countries search
- Two illustrated recommendations per category
- Clear resets the search results
- Local destination times using Intl.DateTimeFormat
- Accessible labels, keyboard focus, and responsive layout
- Contact form opens a mailto draft; no backend or stored submissions

## Run
Open index.html or serve this folder with any static web server. No build step, dependencies, or API keys are required. GitHub Pages can publish the main branch root.

Photos are remotely hosted by Unsplash and used as illustrative destination imagery. Fonts are served by Google Fonts. Network access is required for those assets.
